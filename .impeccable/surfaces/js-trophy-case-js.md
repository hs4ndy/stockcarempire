# Trophy Case
Mode: Experience, inside the established Career interface. Code-led; user specified the grid, per-award dates, More disclosure and 3D inspection.

## Direction contract
THESIS: A collection of earned objects, one trophy per win/title, with honest event provenance.
OWN-WORLD: Existing charcoal panels, Barlow headings/body, red controls and thin grey separators. Trophy metals supply the gold and silver; no replacement visual identity.
STORY: Browse earned trophies, read Year/Race, expand More for the result, then inspect the actual model by orbiting it.
FIRST VIEWPORT: Existing Career header/navigation, Trophy Case next to Career, compact title/count/filter, three equal trophy images across desktop. Each image above title/date and More; phone one column. Inspection uses a large dark stage with a compact details column and explicit Close.
FORM: User-pinned gallery grid; six original Blender models, shared static thumbnails and one on-demand WebGL viewer. No roll needed for this specified composition. Pagination bounds large careers.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
